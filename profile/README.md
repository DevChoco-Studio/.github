# DevChoco-Studio

DevChoco-Studio는 인공지능, 데이터 분석, 자동화 기술을 활용해 실제 문제를 해결하는 소프트웨어와 서비스를 개발하는 기술 조직입니다.

제품 개발과 연구를 함께 진행하며, 음성·영상 처리, 예측 모델, 원격 관리, 웹 서비스 및 브랜드 경험을 하나의 흐름으로 연결하는 것을 목표로 합니다. 검증 가능한 데이터와 재현 가능한 기술을 바탕으로 실용적인 서비스를 만드는 데 집중하고 있습니다.

## 주요 프로젝트

### VoxDub

크리에이터를 위한 음성 보존형 AI 더빙 SaaS 프로젝트입니다.

영상과 자막을 업로드하면 채널 용어집을 반영한 번역, 음성 합성, 타임라인 정렬 과정을 거쳐 다국어 더빙 오디오를 생성합니다. 완성된 결과물은 영상 편집 프로그램이나 YouTube 다국어 오디오 트랙에 활용할 수 있도록 다양한 형식으로 내보낼 수 있습니다.

### DevChoco Control

웹 기반 Windows PC 관리 플랫폼입니다.

각 PC에 설치된 Agent와 웹 관리 화면을 연결해 장치 상태 확인, 명령 실행, 작업 결과 확인, 감사 기록 및 장치 인증 관리를 제공합니다. 여러 대의 PC를 중앙에서 관리할 수 있는 기능을 단계적으로 확장하고 있습니다.

### bitpred

비트코인 시장 데이터를 수집하고 분석하는 시계열 예측 프로젝트입니다.

OHLCV, 파생상품, 온체인, 거시경제 및 심리 데이터를 인과적으로 정렬해 데이터 누수를 방지하고, 변동성과 시장 방향을 분석하는 머신러닝 모델을 연구합니다. 데이터 수집부터 피처 생성, 모델 학습, 평가, 실시간 분석까지의 전체 파이프라인을 포함합니다.

## 기술 방향

DevChoco-Studio는 다음과 같은 방향으로 프로젝트를 개발합니다.

- 인공지능과 데이터 기반의 실용적인 서비스 개발
- 음성, 영상, 텍스트를 연결하는 콘텐츠 처리 기술
- 반복 작업을 줄이는 자동화 및 운영 도구 개발
- 데이터 누수와 과장된 성능을 방지하는 검증 중심의 연구
- 재현 가능하고 유지보수하기 쉬운 소프트웨어 설계
- 제품 개발과 기술 연구를 연결하는 오픈소스 및 문서화

## 우리의 목표

단순히 기술을 구현하는 것을 넘어, 실제 사용자가 지속적으로 활용할 수 있는 제품을 만드는 것을 목표로 합니다.

연구 결과와 개발 과정을 투명하게 기록하고, 검증 가능한 데이터와 명확한 설계를 바탕으로 신뢰할 수 있는 기술을 만들어가겠습니다.
